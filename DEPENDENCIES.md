Dependencies intentionally absent: web framework, browser app, database, Redis, Kafka, Kubernetes, Wasmtime, model SDK, cloud SDK, vector database, GPU stack. Avoid replacing a reviewed safe syscall API with hand-rolled FFI to save trivial compilation size. The dependency-free seed is a small contract core, not a claim that the final runtime needs no dependencies.

## Package and asset diligence
At first online resolution: inspect package owners/source, yanked status, RustSec advisories, build scripts, transitive licenses and MSRV; write metadata and cargo tree snapshot. Use cargo audit and cargo deny installed at verified pinned versions inside the quota area. Offline/advisory-network failure is BLOCKED, not 'no vulnerabilities'. Do not vendor third-party source unless justified and notices are included. Prefer crates.io release checksum over mutable Git branch dependencies. No employer data, fonts, proprietary binary, model weights or third-party screenshot is needed. Original code/docs MIT; every actual third-party dependency keeps its license.

## ABI and syscall policy
Baseline mandatory Landlock rights are those needed for read/execute/write/create/remove/refer/truncate on the declared paths. ABI3 minimum covers truncation; deny newer sensitive operations through seccomp when no equivalent filesystem mediation is available. A higher Landlock ABI is not automatically evidence of full protection: enforce known required rights, inspect crate enforcement result and record ABI/policy version. Unreviewed policy/kernel interactions require a diagnostic refusal or explicit reviewed compatibility decision, never a hidden fallback.

Initial guest syscall policy is default EPERM, architecture mismatch/x32 KILL_PROCESS. Review required static fixture calls: read/write/readv/writev/close, fstat/newfstatat/lseek, openat/openat2/getdents64, mmap/mprotect/munmap/mremap/brk/madvise, rt_sigaction/rt_sigprocmask/rt_sigreturn/sigaltstack, clock_gettime/clock_nanosleep/nanosleep, futex/set_tid_address/set_robust_list/rseq, getpid/getppid/gettid/getuid/geteuid/getgid/getegid, arch_prctl, exit/exit_group, wait4/waitid, fork/vfork, clone with explicit allowed flags and no new-namespace/ptrace flags, setsid/setpgid, kill/tgkill within private PID namespace, execve of Landlock-permitted approved executable, fcntl/dup/dup2/dup3, pipe/pipe2, fsync/fdatasync/ftruncate, mkdirat/unlinkat/renameat2, readlinkat and getrandom if required. Every allowance needs a fixture and reason. No blanket allow-all; no socket, ptrace,bpf,keyctl,io_uring,mount,unshare,setns,memfd_create,sched_setscheduler or arbitrary ioctl. clone3 returns ENOSYS where fixture libc needs fallback; policy changes are versioned and rerun AC-008. This is a reviewable starting set, not a proven production profile.
